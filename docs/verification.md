# Verification

Trust boundaries in Pigeon and what tests or planted defects verify each one.

A trust boundary accepts or rejects untrusted bytes (signatures, log entries, envelopes, frames, sealed files). Everything below runs in `mise run check`, except planted defects (`mise run defects`) and Playwright (`mise run e2e`).

## The map

| Boundary                         | Code                                                                                            | Checked today                                                                                                                                                                                                                                                 | Not checked yet                                            |
| -------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| Signature acceptance             | `packages/core/src/identity/signature.ts`, `signed-kinds.ts`                                    | Wycheproof Ed25519 vectors and the canonical spelling rule (including over a permissive `SubtleCrypto`). Planted defects: `ed25519-s-unchecked`, `ed25519-s-equal-to-order`.                                                                                  | Ed25519 small/mixed-order public keys left to WebCrypto.   |
