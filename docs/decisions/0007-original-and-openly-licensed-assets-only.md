# 0007: Original and openly licensed assets only

Pigeon looks like the XP era but ships no Microsoft-owned assets, only its own art and openly licensed material.

- Status: accepted; the wallpaper is amended by [0011](0011-unsplash-photo-wallpaper.md)
- Date: 2026-11-24

## Context

The goal is an authentic early-2000s feel on a public portfolio. Ripped Windows assets circulate (for example the itch.io "Win XP asset pack", which grants no licence and says the rights belong to Microsoft) and would make the project a copy of Windows rather than its own world.

## Decision

Use XP.css values and bitmaps (MIT), Wine's Tahoma (LGPL 2.1), Tango icons (public domain), and art drawn for Pigeon. No Windows logo, Bliss, Microsoft icons, sounds, cursors or fonts, no "start", no Microsoft product names. Credit sources in the About box and README. The table lives in [design.md](../design.md).

## Consequences

Safe to publish and clearly Pigeon's own. Some things must be drawn by hand (custom icons, wallpaper, sounds), which takes time but is part of the portfolio.
