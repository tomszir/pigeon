Saving Your Data

Everything Pigeon knows about your friends and chats lives in this browser. You can seal a copy of it into a file, to keep or to bring to another device of yours.

Saving a sealed file

1 In Pigeon Messenger, choose File, Export My Data.
2 Choose a passphrase and type it twice. Pick a long one: the file is only as safe as the passphrase.
3 Choose Save as File. Pigeon writes a text file named like Pigeon data 2026-11-25.txt. 

   +------------------------------------------------------------+
   |  Pigeon data 2026-11-25.txt                                |
   |                                                            |
   |  pigeon-sealed:v2:...  <- one long sealed line             |
   |  +------------------------------------------------------+  |
   |  | IN IT:      your name and settings, your friends     |  |
   |  |             and their secrets, everyone you blocked, |  |
   |  |             your friends' lists of devices, and      |  |
   |  |             every chat                               |  |
   |  | NOT IN IT:  any key, your own list of devices        |  |
   |  +------------------------------------------------------+  |
   +------------------------------------------------------------+
Figure 6. What goes in the file, and what doesn't. The sealed part can only be opened with your passphrase.

The file is sealed with your passphrase, made slow and memory-hungry to guess on purpose, so a stranger who finds it can't read it. Guard both: the file holds every chat you have. It also holds each friend's secret, which lets whoever opens it into your private meeting places with that friend, where they can see when your friend is online, their name and devices, and their address. They still can't read or send your messages there: that takes a key that never leaves your device.

Opening it on a device of yours

1 On a device that is already you, linked or recovered, choose File, Import My Data.
2 Choose the file and type its passphrase.
3 Pigeon adds your chats' messages to the ones it has, with the same checks it uses when chats catch up, and adds any friends and blocks this device is missing. Where both have a friend, it keeps its own. It takes your name and settings only if this device has no name yet.
4 Pigeon starts again with everything in.

Good to know
An export file only opens on a device of the same Pigeon. Someone else's file, or one from before this device became you, is refused. It isn't a way to give your friends to someone else.

Saving one conversation as text

To keep a single chat to read later, open it and choose File, Save Conversation As. Pigeon writes it as a plain text file anyone can read, with nothing sealed.
